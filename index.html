Course Learning Outcomes

What a student can do on completion. Written with Bloom's action verbs.

1
Explain
Explain the structure and core functions of an operating system and how it manages CPU, memory, and I/O resources.
2
Analyse
Analyse CPU scheduling and process-synchronisation mechanisms to evaluate concurrency and system performance.
3
Apply
Apply memory-management techniques — paging, segmentation, and virtual memory — to solve resource-allocation problems.
4
Design
Design strategies to detect, prevent, and resolve deadlocks in concurrent systems.
5
Evaluate
Evaluate file-system and storage designs for reliability and efficiency in real-world deployments.

How Android — the OS on most Nigerian smartphones — and the Linux servers behind Paystack and Flutterwave manage CPU, memory, and I/O so apps stay responsive even under heavy transaction load.

Career Relevance
Backend EngineerSite Reliability EngineerPerformance Analyst

Simulate FCFS, Shortest-Job-First, and Round-Robin scheduling on a sample workload and compare the average waiting time of each.

How Jumia's servers use virtual memory and paging to keep many services running on limited RAM during traffic spikes like Black Friday.

Career Relevance
Software EngineerCloud Infrastructure EngineerEmbedded Systems Developer

Q1 / 25 pts

What is virtual memory and why is it important in modern operating systems?

/ 25
Virtual memory is a technique that uses disk storage as an extension of RAM, allowing programs larger than physical memory to run and enabling process isolation.
Q2 / 25 pts

Explain the difference between internal and external fragmentation.

/ 25
Internal fragmentation is wasted memory inside an allocated block. External fragmentation is scattered free memory that cannot be used for large allocations.
